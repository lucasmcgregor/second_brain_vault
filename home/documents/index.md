# home/documents — Documents

## Conventions

- One subject per file, named for the subject: `mortgage-basics.md`, not `notes-3.md`.
- Frontmatter always, with a real `summary` line and `tags`. Summary becomes the registry row; tags are what make search work when the registry does not.
- Record the **source** of anything not original: where it came from, when, and a link.
- Link generously between related documents. In a reference collection the graph is more useful than the folder tree.
- Prefer updating an existing document over creating a near-duplicate. Check the registry first.

## Scanning

1. This index, then the relevant topic index — usually enough.
2. Named files from that registry.
3. Only then a content search, scoped to `documents/`.

If a search finds something the registry does not list, add it to the registry before moving on. This folder is the one most likely to drift, and a stale registry here costs every future lookup.
